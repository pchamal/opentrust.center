    Methodology

    We first probe trust.{domain}, security.{domain}, /{trust,trust-center,security}, and vendor hosts. Misses get a web search for “{company} Trust Center”, then a check that the result is that company’s real security portal. A hit is HTTP 200 plus a trust-center signature. Certifications are read from the public page text.
